# Orthodoxy or Heresy?

A live, Kahoot-style classroom game for Theology. Students vote on their iPads; the board shows the answer and explanation after every round, then each student's Orthodox vs. Heretic score.

- **Students:** open https://elastres25.github.io/orthodoxy-or-heresy/ (or scan the QR code on the board), type the game code and their name.
- **Teacher (projector):** open https://elastres25.github.io/orthodoxy-or-heresy/#host

To change the statements, edit the `ROUNDS` list near the top of the script in `index.html` (`answer: "H"` = Heresy, `"O"` = Orthodox).
